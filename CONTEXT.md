# FRNDLY Project Context

## Project Name

FRNDLY

## Purpose

Web application for managing a garment/convection business.

## Main Business

Custom garment and event-related products such as:

- T-shirts
- Lanyards
- Jackets
- ID cards
- Event attributes
- Other custom products

## Core Modules

- Dashboard
- Customers
- Products
- Orders
- Payments
- Invoices
- Production
- Shipping
- Reviews
- Testimonials
- Reports

## Order Status

Draft
→ Menunggu DP
→ DP Masuk
→ Proses
→ Lunas

## Payment

DP is paid once.

There is currently no payment gateway.

Payment communication is handled through WhatsApp.

## Invoice

Invoice numbering format:

INV-YYYYMMDD-000

## Development Principle

The existing application is partially implemented.

AI must understand and preserve existing functionality before implementing new functionality.
